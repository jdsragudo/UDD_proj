# Komorebi — Calm Focus Sanctuary

A calm, aesthetic Pomodoro and productivity web app with soft organic palettes, drift-free timing, procedural Web Audio ambient soundscapes, task intentions, Zen Mode, and a 7-day focus rhythm tracker.

## Run Locally

```bash
npm run dev
```

Then open `http://localhost:5173`.

## Run Tests

```bash
npm test
```
